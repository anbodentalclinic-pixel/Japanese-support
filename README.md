# 国語学習サポート

中1国語(2学期期末)の家庭学習用アプリ(スマホ向け)。

- 漢字5問(紙に書いて自己採点、間違えた漢字は2日後に再出題)
- 言葉を紡ぐ(記述):問い → 根拠 → 言いかえ → つなぐ → 書く、段階1〜3
- 作品の地図:年表と対比/気持ちの曲線
- ワークの見直し、文節チェック
- 記録はブラウザ(localStorage)に保存

## 記録（Google スプレッドシート「拓真 国語記録」）

- アプリを開いたときと、答えを記録したとき(3秒後)に、記録の全体を Apps Script のウェブアプリへ送る
- スプレッドシート側は「言葉を紡ぐ」「漢字」「ワークの見直し」「文節チェック」の各シートを最新の記録で書き換える
- 記録が今より少ない端末(リセットした端末・ほかの人の端末)からは上書きしない。届いた記録は「受信ログ」に残る

## 保護者おためしモード

- ホーム画面の下の「保護者おためしモード」を2秒長押しでオン、もう一度2秒長押しでオフ
- オンの間は記録を保存せず、スプレッドシートにも送らない。オフにするともとの記録に戻る
- 60分たつと自動でオフ
