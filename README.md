# 国語学習サポート

中1国語(2学期期末)の家庭学習用アプリ(スマホ向け)。

- 漢字5問(紙に書いて自己採点、間違えた漢字は2日後に再出題)
- 言葉を紡ぐ(記述):問い → 根拠 → 言いかえ → つなぐ → 書く、段階1〜3
- 作品の地図:年表と対比/気持ちの曲線
- ワークの見直し、文節チェック
- 「言葉」をもつ鳥、シジュウカラ：構成マップ（仮説→検証1→疑問→検証2→結論の並べ替え、事実と意見の仕分け）、言葉を紡ぐ7問、ワークの見直し6問
- 漢字：シジュウカラと漢字に親しもう3を追加。新しい漢字は教材ごとに順番に出る
- 文の組み立てラボ（文法への扉2）：主・述／修飾・被修飾／接続・独立／並立・補助／文の成分の5項目32問。結果は「文節チェック」シートに入る
- 記録はブラウザ(localStorage)に保存

- 確認ドリル（自動で丸つけ）：項目を立てて書こう・読み手の立場に立つ13問、方言と共通語15問、漢字の音訓24問、漢字に親しもう2 10問。「まちがえた問題だけ」もできる。結果は「文節チェック」シートに入る
- 漢字：方言と共通語・漢字の音訓・漢字に親しもう2を追加

## テスト範囲を見わたす

- ホーム画面の一番上から開く。期末テスト（11/19）までの日数、本人が立てた計画のチェックリスト、単元ごとの進み具合（作品の地図・言葉を紡ぐ・見直し・漢字・文法ラボ）、アプリに入っていない範囲のチェックリスト
- 計画のチェックは「ワークの見直し」シートに「自分の計画」として送られる

## 記録（Google スプレッドシート「拓真 国語記録」）

- アプリを開いたときと、答えを記録したとき(3秒後)に、記録の全体を Apps Script のウェブアプリへ送る
- スプレッドシート側は「言葉を紡ぐ」「漢字」「ワークの見直し」「文節チェック」の各シートを最新の記録で書き換える
- 記録が今より少ない端末(リセットした端末・ほかの人の端末)からは上書きしない。届いた記録は「受信ログ」に残る

## 取り組み方の記録

- 言葉を紡ぐ：1問にかかった時間と、段階1で「確かめる」を押してまちがえた回数（並べ直し）を残す
- 漢字：問題が出てから「答えを見る」を押すまでの時間（紙に書いている時間の目安）を、漢字ごとに直近6回まで残す
- 画面の表示は変わらない

## 保護者おためしモード

- ホーム画面の下の「保護者おためしモード」を2秒長押しでオン、もう一度2秒長押しでオフ
- オンの間は記録を保存せず、スプレッドシートにも送らない。オフにするともとの記録に戻る
- 60分たつと自動でオフ
